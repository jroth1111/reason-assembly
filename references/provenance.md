# Design provenance — v4

Schema v4 replaces heuristic pass-at-council, scalar independence, route-pair
reliability, lexical diversity, binary verification, generic debate, and
judge-only truth.

It uses dependency-free signed-hash representations, exact binomial bounds,
decayed co-failure, adaptive verification, guarded reliability, route epochs,
and claim genealogy with transitive taint. Retrieved content is data:
instruction-like passages are quarantined and only source-tagged claims are
shared with models.

No local model weights, dense mixture layers, learned router models, parameter
merging, or latent-state fusion are introduced. Luna remains utility-only.
